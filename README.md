# Power Play - 10 Steps To Become A Drummer

An interactive drum-learning web app by Peter Power. It is a plain web page: one `index.html`, plus images and drum sounds in `public/`.

## Folder layout
- `index.html` - the whole app (text, steps, grids, kit, sounds engine)
- `public/audio/` - the seven drum sounds (bass drum, snare, hi-hat, three toms, cymbal)
- `public/cover.jpg` - the title-page cover image
- `public/logo.svg` - the Power Play logo
- `package.json` - lets tools such as Base44 treat it as a normal web project (Vite)

## Run it on your own computer
    npm install
    npm run dev

## Import into Base44
Put these files in a GitHub repository, then in Base44 choose "Bring your own project" and "GitHub project" and pick the repository.
